# Web Technology Laboratory Programs

This repository contains practical programs for Web Technology Laboratory based on the Third Year Computer Engineering curriculum. The projects demonstrate frontend and backend web development using HTML, CSS, JavaScript, XML, Java Servlets, JSP, PHP, AngularJS, Struts, and EJB.

---

## Technologies Used

- HTML5
- CSS3
- JavaScript
- XML, DTD, XSD, XSL
- Java Servlet
- JSP
- PHP
- MySQL
- AngularJS
- Struts Framework
- Enterprise Java Beans (EJB)

---

# Programs Included

## 1. Restaurant Website using HTML & CSS

Implementation of a client-side website using:

- Heading tags
- Tables and lists
- Images and hyperlinks
- Forms and frames
- Internal CSS
- Inline CSS
- External CSS

### Files
- `index.html`
- `style.css`

---

## 2. XML Document with DTD and XML Schema

Design an XML document to store employee information.

### Features
- XML validation using DTD
- XML validation using XML Schema (XSD)
- XML display using CSS/XSL

### Sample Fields
- Employee ID
- Employee Name
- Department
- Salary

---

## 3. JavaScript Calculator Application

Simple calculator implemented using JavaScript.

### Operations
- Addition
- Subtraction
- Multiplication
- Division
- Square of Number

### Features
- Input validation
- Alert messages
- Prompt windows

### Technologies
- HTML
- CSS
- JavaScript

---

## 4. Servlet Program using MySQL

Display records from MySQL database using Java Servlet.

### Database Table
```sql
ebookshop(
    book_id,
    book_title,
    book_author,
    book_price,
    quantity
)
```

### Features
- JDBC Connectivity
- SQL SELECT Query
- Dynamic HTML generation

---

## 5. JSP Program using MySQL

Display student information using JSP.

### Database Table
```sql
students_info(
    stud_id,
    stud_name,
    class,
    division,
    city
)
```

### Features
- JSP scripting
- Database connectivity
- Dynamic table display

---

## 6. PHP CRUD Application

Dynamic web application using PHP and MySQL.

### Functions
- Add Records
- Update Records
- Delete Records
- Retrieve Records

## 7. Struts Login Validation Application

Login form validation using Struts framework.

### Validations

- Empty field validation

### Output

## 8. AngularJS Registration and Login Application

Registration and login form using AngularJS.

### Fields

### Features

## 9. EJB Business Logic Application

Implementation of business logic using Enterprise Java Beans.

Bank transaction system:
- Deposit Amount
